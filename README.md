# Tailly

## 📌 Проект

Платформа для поиска и бронирования услуг по уходу за домашними животными с системой привлечения специалистов и интернет-магазином товаров для питомцев.
**Зона ответственности:** серверная архитектура платформы, управление пользователями и специалистами, бронирование услуг, работа с профилями питомцев, продажа товаров и управление контентом.

## ✨ Достижения

- Реализовала микросервисную архитектуру с разделением системы на AuthService, SpecialistService, BookingService, ShopService, ClientProfileService и PostsService.
- Реализовала API Gateway на базе Ocelot для централизованной маршрутизации запросов.
- Организовала асинхронное взаимодействие между сервисами через MassTransit и RabbitMQ.
- Реализовала JWT-аутентификацию и работу с Access Token / Refresh Token.
- Разработала процессы регистрации, верификации, восстановления и изменения учётных данных.
- Реализовала полный цикл привлечения специалистов: подача заявки, модерация и создание профиля.
- Реализовала бронирование услуг и управление статусами заказов.
- Разработала интернет-магазин с каталогом товаров, корзиной, избранным и оформлением заказов.
- Внедрила Redis для хранения временных данных с использованием TTL.
- Организовала хранение данных микросервисов в PostgreSQL.
- Разработала 330 модульных тестов с использованием xUnit, Moq и FluentAssertions.

## 🌐 Технологический стек

### Backend

- **Язык:** C#
- **Платформа:** .NET 8
- **Фреймворк:** ASP.NET Core WebAPI
- **Архитектура:** Microservices
- **ORM:** Entity Framework Core

### Микросервисная архитектура

- **API Gateway:** Ocelot
- **Синхронное взаимодействие:** REST API
- **Асинхронное взаимодействие:** MassTransit
- **Брокер сообщений:** RabbitMQ

### База данных

- **СУБД:** PostgreSQL
- **Кэширование:** Redis
- **Миграции:** Entity Framework Core

### Безопасность

- **Аутентификация:** JWT
- **Токены:** Access Token, Refresh Token
- **Авторизация:** Role-based access control
- **Валидация:** FluentValidation

### Инфраструктура

- **Контейнеризация:** Docker
- **Оркестрация:** Docker Compose

### Тестирование

- **Фреймворк:** xUnit
- **Мокирование:** Moq
- **Assertions:** FluentAssertions
